# Spectra 功能规格说明书

> 本文档定义 Spectra 各功能的详细规格、行为边界和交互细节。

---

## 一、导入模块

### 1.1 文件夹导入

| 项目 | 规格 |
|------|------|
| **触发方式** | 主菜单 "File → Import Folder" 或快捷键 `Ctrl+I` |
| **选择器** | 原生文件夹选择对话框（`file_picker`，跨平台） |
| **导入行为** | 递归扫描所选文件夹及其子文件夹 |
| **文件类型** | 默认：`.jpg` `.jpeg` `.png` `.tif` `.tiff` `.webp` `.bmp` + RAW（`.cr2` `.cr3` `.nef` `.arw` `.dng` `.raf` `.rw2`） |
| **去重策略** | 基于文件路径唯一约束；相同路径不重复导入 |

### 1.2 拖拽导入

| 项目 | 规格 |
|------|------|
| **触发方式** | 从文件资源管理器拖拽文件/文件夹到应用窗口 |
| **视觉反馈** | 拖入时窗口边缘高亮 + 显示 "释放以导入" 提示 |
| **支持多源** | 同时拖入多个文件夹和文件 |
| **混合类型** | 自动过滤掉非图片文件 |

### 1.3 增量扫描

| 项目 | 规格 |
|------|------|
| **触发方式** | 应用启动时 + `watcher` 实时监听 |
| **监听粒度** | 文件创建、删除、重命名；文件夹创建/删除 |
| **扫描策略** | 首次全量扫描 → 后续仅处理变更文件 |
| **忽略规则** | 忽略隐藏文件夹（以 `.` 开头）、系统文件夹、超过 500MB 的文件 |

### 1.4 首次扫描体验

| 阶段 | 交互 |
|------|------|
| 扫描中 | 底部状态栏显示 "正在扫描文件夹... (123/4567 个文件)" |
| 元数据处理中 | "正在读取元数据... (45/123 张)" |
| 缩略图生成中 | "正在生成缩略图... (已完成 30%)" |
| 完成 | 状态栏显示 "就绪 - 共 4567 张照片" |

## 二、浏览模块

### 2.1 网格视图

| 项目 | 规格 |
|------|------|
| **默认布局** | 三栏布局（文件夹树 | 网格 | 信息面板） |
| **缩略图尺寸** | 可调节（预设：小 = 120px / 中 = 180px / 大 = 260px），滑块控制 |
| **自适应列数** | 根据面板宽度和缩略图尺寸自动计算列数 |
| **滚动** | 平滑滚动，`GridView.builder` 懒加载 |
| **选中状态** | 蓝色边框 + 覆盖层显示序号 |
| **悬停状态** | 轻微放大 + 阴影（1.02x scale） |
| **上下文菜单** | 右键打开：评分 → 旗标 → 色标 → 添加标签 → 移出目录 |

### 2.2 列表视图

| 项目 | 规格 |
|------|------|
| **布局** | 单列列表，每行：缩略图(64px) + 文件名 + 日期 + 尺寸 + 星级 + 旗标图标 |
| **排序** | 点击列头排序（名称/日期/大小/评分/拍摄时间） |
| **用途** | 适合快速浏览和元数据对比 |

### 2.3 单张预览

| 项目 | 规格 |
|------|------|
| **触发** | 网格/列表中点击照片，右侧信息面板显示大图预览 |
| **操作** | 信息面板中可评分、旗标、色标、查看完整 EXIF |
| **尺寸** | 预览图最大 1024px（保持宽高比） |

### 2.4 全屏查看器

| 项目 | 规格 |
|------|------|
| **触发** | 双击照片 或 按 `Enter` |
| **退出** | `Esc` 或 单击关闭按钮 |
| **缩放** | 滚轮缩放 / `Ctrl+滚轮` / 手势缩放 |
| **平移** | 鼠标拖拽平移 |
| **切换** | 方向键左/右切换上一张/下一张 |
| **全屏操作** | 全屏模式下可继续评分/旗标（快捷键） |
| **查看模式** | 适应窗口 / 100% 原尺寸 / 填充宽度 |

## 三、分类模块

### 3.1 星级评分

| 项目 | 规格 |
|------|------|
| **等级** | 0-5 星（0 = 未评分） |
| **快捷键** | `0`=清除评分, `1`=1星, ..., `5`=5星 |
| **交互** | 点击星星设置；右键点击星级数字可快速清除 |
| **显示** | 网格中：缩略图右下角显示星星图标（3星+显示）; 信息面板：完整 5 星 |
| **批量** | 选中多张后，按数字键 → 所有选中照片设为该星级 |

### 3.2 旗标 (Pick / Reject)

| 项目 | 规格 |
|------|------|
| **状态** | 无旗标 / Pick（白色旗标） / Reject（黑色旗标+ X） |
| **快捷键** | `P` = Pick, `U` = Unpick（清除）, `X` = Reject |
| **交互** | 按 P 设为 Pick，再按 P 不变；按 U 清除；按 X 设为 Reject |
| **显示** | 网格中：缩略图左上角显示旗标图标 |
| **筛选** | Filter bar 可筛选 "仅 Pick" / "仅 Reject" / "无旗标" |
| **批量** | 选中多张后，P/U/X 同时作用于所有选中照片 |

### 3.3 色标

| 项目 | 规格 |
|------|------|
| **颜色** | 红 / 黄 / 绿 / 蓝 / 紫 / 灰（共 6 色） |
| **快捷键** | `F1`=红, `F2`=黄, `F3`=绿, `F4`=蓝, `F5`=紫, `F6`=灰, `F7`=清除 |
| **交互** | 按 F1-F6 设置对应色标；再次按相同键清除该色标；F7 清除所有色标 |
| **显示** | 网格中：缩略图底部显示颜色条；信息面板显示色标圆点 |
| **批量** | 选中多张后，F1-F7 同时作用于所有选中照片 |

### 3.4 关键词标签

| 项目 | 规格 |
|------|------|
| **标签类型** | 层级标签（支持父/子/孙），多对多关系 |
| **CRUD** | 创建、编辑、删除、合并标签 |
| **添加方式** | 右键 → "添加标签" → 搜索/选择已有标签 或 输入新建 |
| **批量添加** | 选中多张照片 → 添加标签 → 所有选中照片获得该标签 |
| **标签树** | 左侧面板可切换到"标签"视图，树形浏览标签 |
| **标签过滤** | 点击标签 → 过滤出所有包含该标签（含子标签）的照片 |
| **标签统计** | 标签旁显示该标签下的照片数量 |

### 3.5 批量操作

| 操作 | 选中后操作 |
|------|-----------|
| 批量评分 | 按数字键 0-5 |
| 批量旗标 | 按 P/U/X |
| 批量色标 | 按 F1-F7 |
| 批量标签 | 右键 → 添加标签 → ... |
| 批量移除标签 | 选中 → 右键 → 移除标签 → 选择要移除的标签 |
| 批量导出 | 选中 → 右键 → 导出选中（Phase 2+） |
| 全选 | `Ctrl+A` |
| 取消全选 | `Esc`（当有选中时） |

## 四、搜索与筛选模块

### 4.1 筛选栏 (Filter Bar)

位于网格上方的水平工具栏：

```
[文件夹: Wedding]  [⭐ ≥3 星]  [🚩 Pick]  [🏷️ 色标: 红]  [📅 日期: 2026-06]
[📷 相机: Sony A7IV]  [🔍 搜索: bride]
                   [清空所有筛选]  [保存为智能收藏集]
```

| 条件 | 可选值 |
|------|--------|
| 星级 | ≥1 / ≥2 / ≥3 / ≥4 / =5 / 未评分 |
| 旗标 | Pick / Reject / 无旗标 / 不限 |
| 色标 | 红/黄/绿/蓝/紫/灰/无色/不限 |
| 日期范围 | 今天 / 本周 / 本月 / 今年 / 自定义范围 |
| 相机 | 从数据库自动提取相机型号列表 |
| 镜头 | 从数据库自动提取镜头列表 |
| 关键词搜索 | 搜索照片文件名、标签名、标题、描述 |

### 4.2 组合筛选逻辑

- 多个条件之间为 **AND** 关系
- 同一条件内支持多选（如多个色标 → OR）
- 搜索结果 = 照片文件名匹配 + 标签名匹配 + 描述匹配
- 排序支持：拍摄日期 / 导入日期 / 星级 / 文件名

### 4.3 快速搜索

| 项目 | 规格 |
|------|------|
| **触发** | `Ctrl+F` 定位到搜索框 |
| **实时搜索** | 输入即搜索（300ms debounce） |
| **搜索范围** | 文件名、标签、标题、描述、相机型号 |
| **清除** | 搜索框右侧 × 按钮或 `Esc` |

## 七、非功能性需求

### 7.1 性能指标

| 指标 | 目标 | 测量方法 |
|------|------|----------|
| 应用启动时间 | ≤3秒（1万张目录） | 从双击到网格可交互 |
| 网格滚动帧率 | 60fps | Flutter DevTools |
| 评分响应延迟 | ≤50ms | 按键到 UI 更新 |
| 全屏照片切换 | ≤100ms | 按键到新照片显示 |
| 缩略图首次生成 | 100张/秒（SSD） | 批量生成速率 |
| 文件夹切换 | ≤200ms（1万张） | 选中文件夹到网格显示 |
| 搜索响应 | ≤300ms debounce | 输入到结果展示 |

### 7.2 资源限制

| 资源 | 约束 |
|------|------|
| 内存（空闲） | ≤200 MB |
| 内存（浏览 1 万张） | ≤500 MB |
| 磁盘缓存 | ≤5 GB（缩略图缓存上限） |
| CPU（空闲） | ≤1% |
| CPU（批量缩略图） | 可配置后台优先级 |

### 7.3 兼容性

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 20H2+ / Windows 11 |
| 文件系统 | NTFS（推荐）、FAT32/exFAT（只读支持） |
| RAW 格式（缩略图） | CR2/CR3/NEF/ARW/DNG/RAF/RW2（通过 Windows Shell） |
| 屏幕分辨率 | 1280×800 最小；推荐 1920×1080+ |

### 7.4 安全性

- 应用永不联网（Phase 1-3）
- 不收集任何用户数据
- 不修改原始照片文件
- 数据库文件加密（可选，Phase 2+）
