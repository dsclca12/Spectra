## Short project post

### English

I’m building **Spectra**, a desktop photo culling and organization app for photographers on Windows and Linux.

It focuses on the work before editing: import a shoot, review images with keyboard shortcuts, apply ratings/flags/color labels, add hierarchical tags, and find keepers with combined filters. Classification stays in a local SQLite catalog; original photos are not modified.

Download the latest release or explore the source: https://github.com/dsclca12/Spectra

Feedback from photographers and contributions are welcome.

### 中文

我在做 **Spectra**：一款面向 Windows 和 Linux 摄影师的桌面照片筛选与整理工具。

它专注于后期编辑前的工作：导入拍摄文件夹，用键盘快速浏览，设置星级、旗标和色标，添加层级标签，再通过组合筛选找到想保留的照片。分类信息保存在本地 SQLite 目录中，不会改动原始照片。

下载最新版本或查看源码：https://github.com/dsclca12/Spectra

欢迎摄影师试用并反馈问题，也欢迎参与贡献。
