# Spectra UX 设计指南

> 本文档定义 Spectra 的用户体验设计原则、交互模式和视觉规范。

---

## 一、设计原则

### 1.1 核心原则

| 原则 | 说明 |
|------|------|
| **速度即特征** | 每一次操作都应在 100ms 内给出反馈。专业摄影师每秒都在做筛选决策，延迟就是成本 |
| **键盘优先** | 所有分类操作必须可用纯键盘完成。鼠标是辅助，不是必需 |
| **非破坏性** | 用户永远不用担心操作会损坏原始文件。撤销操作随时可用 |
| **信息密度可控** | 提供从"极简"到"详尽"的渐变，让用户按需调节 |
| **一致性** | 相同的操作在网格、列表、全屏等所有视图中的行为完全一致 |
| **离线可用** | 所有核心功能不依赖网络 |

### 1.2 与竞品的差异化体验

| 场景 | Photo Mechanic 做法 | Spectra 做法 |
|------|-------------------|-------------|
| UI 风格 | 原生 Win32，信息密集 | Fluent Design，层级清晰，可折叠面板 |
| 标签 | 平面列表 | 层级树 + 自动补全 + 标签统计 |
| 预览 | 简单缩放 | 全屏查看器 + 元数据叠加 |
| 筛选 | 基础过滤 | 组合筛选 + 智能收藏集 |

### 2.2 面板可调性

| 面板 | 默认宽 | 最小 | 最大 | 折叠 |
|------|--------|------|------|------|
| 左栏（文件夹/标签树） | 200px | 150px | 400px | ✅ `Ctrl+B` |
| 右栏（信息面板） | 280px | 220px | 500px | ✅ `Ctrl+Shift+I` |
| 筛选栏 | - | - | - | ✅ 可隐藏 |
| 状态栏 | 30px | - | - | ✅ 可隐藏 |

### 2.3 响应式断点

| 窗口宽度 | 行为 |
|----------|------|
| < 900px | 自动隐藏左栏，保留右栏 |
| < 700px | 隐藏左栏和右栏，网格占满 |
| < 500px | 单列网格 |

### 3.2 选中与多选

| 操作 | 行为 |
|------|------|
| 单击 | 选中单张，取消其他选中 |
| Ctrl+单击 | 切换该张的选中状态 |
| Shift+单击 | 范围选中（从上次选中到当前） |
| Ctrl+A | 全选当前视图所有照片 |
| Esc | 取消全选 |
| 拖拽选框 | 在网格空白处拖拽画框多选 |

选中计数在状态栏显示 "选中 N 张"。

## 五、动画与反馈

### 5.1 微交互动画

| 场景 | 动画 | 时长 |
|------|------|------|
| 缩略图悬停 | 缩放 1.0 → 1.02 + 阴影 | 150ms ease-out |
| 选中切换 | 边框淡入 | 100ms |
| 星级点击 | 星星弹出 + 缩放 | 200ms spring |
| 旗标切换 | 图标旋转 + 淡入 | 150ms |
| 面板展开/折叠 | 水平滑动 | 200ms ease |
| 全屏切换 | 缩放淡入 | 200ms ease |
| 新建标签 | 标签卡片滑入 | 150ms ease |
| 筛选结果更新 | 网格交叉淡入 | 200ms ease |

### 5.2 进度指示

| 场景 | 指示方式 |
|------|----------|
| 缩略图加载中 | 灰色占位块 + 居中旋转进度指示器 |
| 缩略图加载失败 | 文件图标占位 + 红色角标 |
| 批量操作中 | 状态栏显示 "正在应用... (5/50)" |
| 首次扫描 | 状态栏进度条 + "正在扫描..." |
| 缩略图后台生成 | 状态栏 "缩略图生成中 (67%)" |

## 六、无障碍

| 方面 | 要求 |
|------|------|
| 键盘导航 | 所有功能可通过键盘完成 |
| 高对比度 | 系统高对比度模式兼容 |
| DPI 缩放 | 支持 100%-200% DPI 缩放 |
| 屏幕阅读 | 所有图标按钮含语义化 label |
| 颜色依赖 | 不单独依赖颜色传递信息（形状+颜色双重编码） |

## 七、错误与边界状态

### 7.1 空状态

```
📂 文件夹为空:
  ┌─────────────────────┐
  │                     │
  │      📷             │
  │  还没有照片          │
  │  拖拽照片到此，      │
  │  或点击"导入文件夹"  │
  │                     │
  │  [导入文件夹]        │
  └─────────────────────┘

🔍 搜索结果为空:
  ┌─────────────────────┐
  │                     │
  │      🔍             │
  │  没有匹配的照片      │
  │  试试调整筛选条件    │
  │                     │
  │  [清空所有筛选]      │
  └─────────────────────┘
```

### 7.2 错误状态

| 场景 | 用户可见提示 |
|------|-------------|
| 文件夹无法访问 | 状态栏 "⚠️ 文件夹访问被拒绝"，文件夹树中红色警告图标 |
| 缩略图生成失败 | 缩略图占位 + 角标，hover 显示 "缩略图生成失败" |
| 文件已被移动/删除 | 照片显示灰色覆盖层 + "文件缺失" 角标 |
| 数据库错误 | 对话框 "数据库错误，请联系支持" + 错误日志路径 |
