# Spectra 路线图

> 本文档定义 Spectra 的版本规划、里程碑和发布节奏。

---

## 一、版本策略

### 发布节奏

| 阶段 | 频率 | 目标 |
|------|------|------|
| **Pre-alpha** | 内部迭代 | 核心功能可用性验证 |
| **Alpha** | 每 2-3 周一次 Build | 内部测试 + 早期反馈 |
| **Beta** | 每月发布 | 公开测试 + 问题修复 |
| **Stable** | 按里程碑发布 | 生产环境可用 |

### 版本命名

- **v0.1.x** — MVP Phase（主要功能集中发布）
- **v0.2.x** — 专业工作流
- **v1.0.0** — 正式版

---

## 二、Phase 1 — MVP (v0.1.x)

**目标**：实现专业摄影师核心分类工作流的闭环，达到可日常使用的程度。

### 里程碑

| 里程碑 | 周次 | 版本 | 功能完成 | 验收标准 |
|--------|------|------|----------|----------|
| **M1: 基建** | W2 | v0.1.0-alpha.1 | Drift 数据库 + Riverpod 架构 + 项目结构 | 数据库可读写，DAO 单元测试通过 |
| **M2: 导入** | W4 | v0.1.0-alpha.2 | 文件夹导入 + 拖拽 + 增量扫描 + EXIF 读取 + 缩略图生成 | 成功导入 1000 张照片并显示缩略图 |
| **M3: 浏览** | W6 | v0.1.0-alpha.3 | 网格视图 + 列表视图 + 全屏查看器 + 键盘导航 | 1 万张照片网格滚动 60fps |
| **M4: 分类** | W8 | v0.1.0-beta.1 | 评分/旗标/色标 + 标签系统 + 批量操作 + 组合筛选 | 纯键盘完成全部分类操作 |
| **M5: 发布** | W10 | v0.1.0-beta.2 | 性能优化 + 错误处理 + MSIX 打包 | 5 万张测试通过，安装包正常运行 |

### WBS（工作分解结构）

```
Week 1-2: S1 基建
  ├── Day 1-2: flutter create + 目录结构 + pubspec.yaml
  ├── Day 3-4: Drift Schema 定义 + 数据库初始化
  ├── Day 5-6: DAO 实现 + 单元测试
  ├── Day 7-8: Riverpod Provider 框架搭建
  ├── Day 9-10: 主题系统 + 基础 UI 组件
  └── Day 11-12: 窗口管理 + 布局框架

Week 3-4: S2 导入
  ├── Day 1-3: 文件夹选择器 + 文件系统遍历
  ├── Day 4-5: watcher 增量扫描
  ├── Day 6-8: exif_reader 集成 + EXIF 字段映射
  ├── Day 9-10: 缩略图生成 + 分级缓存
  └── Day 11-12: 拖拽导入 (desktop_drop)

Week 5-6: S3 浏览
  ├── Day 1-3: 自适应网格视图 (PhotoGrid)
  ├── Day 4-5: 列表视图 (PhotoList)
  ├── Day 6-8: 全屏查看器 (extended_image)
  ├── Day 9-10: 信息面板 + EXIF 展示
  └── Day 11-12: 键盘导航 + 快捷键框架

Week 7-8: S4 分类
  ├── Day 1-2: 星级评分 (StarRating)
  ├── Day 3-4: 旗标系统 (Pick/Reject)
  ├── Day 5-6: 色标系统 (ColorLabel)
  ├── Day 7-8: 标签系统 (TagManager + TagChip)
  ├── Day 9-10: 批量操作 + FilterBar
  └── Day 11-12: 集成测试 + 边界情况

Week 9-10: S5 打磨
  ├── Day 1-3: 1万/5万张性能测试 + 优化
  ├── Day 4-5: 缩略图生成流水线优化
  ├── Day 6-7: 内存优化 + ImageCache 调优
  ├── Day 8-9: 错误处理 + 日志系统
  └── Day 10: MSIX 打包 + 安装测试
```

## 三、Phase 2 — 专业工作流 (v0.2.x)

**目标**：完善元数据写入、导出、备份等生产环境所需功能。

### 功能清单

| 功能 | 预估工时 | 说明 |
|------|----------|------|
| IPTC XMP 写入 | 3周 | exiv2 FFI 或 win32 COM 方案评估 + 实现 |
| RAW 缩略图增强 | 2周 | Windows Shell IShellItemImageFactory 集成 |
| 收藏集管理 | 2周 | UI + 智能规则自动执行 |
| 智能导出 | 2周 | 模板引擎 + 变量替换 + 批量导出 |
| 导入时备份 | 1周 | 第二存储位置备份 |
| 批量重命名 | 1周 | 基于元数据的变量重命名 |
| 设置页面 | 1周 | 偏好设置 + 存储管理 |

**总预估**：6-8 周

## 四、Phase 3 — 进阶功能 (v0.3.x+)

**目标**：扩展应用场景，支持更多专业需求。

| 功能 | 优先级 | 备注 |
|------|--------|------|
| 地图视图 | P2 | GPS 位置可视化，Leaflet/MapLibre |
| 水印导出 | P2 | 文字/图片水印覆盖 |
| 脚本扩展 | P3 | Lua/Python 脚本自动化 |
| 局域网协作 | P3 | 共享目录/协作选片 |
| 视频支持 | P3 | 视频缩略图 + 基础分类 |
| 相机制造商色彩 | P3 | 嵌入相机色彩配置文件 |
| 备份与恢复 | P2 | 数据库+缓存打包备份 |
| 性能仪表盘 | P2 | 应用内部性能监控面板 |

## 六、依赖项与风险

### 外部依赖评估

| 依赖项 | Phase | 评估结果 | 替代方案 |
|--------|-------|----------|----------|
| `exif_reader` | 1 | ✅ 成熟，纯 Dart | `exif` 包（停止更新） |
| `drift` | 1 | ✅ Flutter Favorite | `sqflite`（无类型安全） |
| `watcher` | 1 | ✅ 纯 Dart，广泛使用 | `dart:io` Directory.watch |
| `desktop_drop` | 1 | ✅ Windows 支持 | 手动 FileDrag 监听 |
| `extended_image` | 1 | ✅ 活跃维护 | `photo_view`, `InteractiveViewer` |
| `window_manager` | 1 | ✅ Windows 支持 | `dart:ffi` 手动调用 |
| `win32` (FFI) | 1 | ✅ 微软官方维护 | `dart:ffi` 手写 |
| `exiv2` (FFI) | 3 | ⚠️ 需要手动编译 DLL | Windows COM API |
