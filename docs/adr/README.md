# Architecture Decision Records (ADR)

This directory contains Architecture Decision Records for Spectra.

Each ADR documents a significant architectural decision, including the context, options considered, decision, and consequences.

## Index

| # | Title | Status |
|---|-------|--------|
| 001 | [SQLite + Drift as Local Database](001-sqlite-drift-database.md) | ✅ Accepted |
| 002 | [Riverpod for State Management](002-riverpod-state-management.md) | ✅ Accepted |

## Template

```markdown
# N. Title

## Status

[Proposed | Accepted | Deprecated | Superseded]

## Context

[What is the issue motivating this decision?]

## Decision

[What is the change being proposed?]

## Consequences

[What becomes easier or more difficult to do?]
```
